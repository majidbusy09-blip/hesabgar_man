# حسابگر من (hesabgar_man)

ماشین‌حساب علمی و ابزارهای مالی شخصی — اپلیکیشن Flutter با رابط فارسی.

## امکانات

- ماشین‌حساب ساده و علمی
- حافظه (MC / MR / M+ / M−)
- حالت درجه / رادیان (DEG / RAD)
- تاریخچه محاسبات
- تایپ دستی فرمول
- تم روشن / تاریک
- پشتیبانی از حالت افقی (landscape)

## تب‌های در حال توسعه

- محاسبات مالی
- ردیاب هزینه‌ها
- تقویم شمسی

## اجرا

```bash
flutter pub get
# فونت Vazirmatn را در assets/fonts قرار دهید
flutter run
```

## بیلد APK

با GitHub Actions روی push به main به‌صورت خودکار بیلد می‌شود.
