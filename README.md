# حسابگر من

**ماشین‌حساب هوشمند + ابزارهای مالی شخصی** به زبان فارسی

اپلیکیشن سبک و کاربردی برای محاسبات روزمره، علمی و حسابداری، به‌همراه تقویم شمسی، مدیریت هزینه و ابزارهای مالی (سود سپرده، قیمت طلا و مبدل واحد).

---

## امکانات

### ماشین‌حساب
- **حالت ساده** — چهار عمل اصلی، درصد و پرانتز
- **حالت علمی** — سینوس، کسینوس، لگاریتم، ریشه، فاکتوریل، توان، ثابت‌های π و e
- **حالت حسابداری** — شبیه ماشین‌حساب اداری (Sharp / Casio):
  - جمع و تفریق فوری با ثابت (`+=` / `−=`)
  - ضرب و تقسیم با تأیید مساوی
  - دکمه `۰۰۰`، جداکننده هزارگان، نوار عملیات (Tape)
  - درصد به‌سبک حسابداری (`۱۰۰ × ۲۵ ٪ = ۲۵`)
- حافظه (`MC` / `MR` / `M+` / `M−`)
- تاریخچه محاسبات
- حالت زاویه DEG / RAD
- پیش‌نمایش زنده نتیجه

### مالی و هزینه
- ثبت و پیگیری **هزینه‌ها** با تاریخ شمسی
- محاسبه **سود سپرده**
- **قیمت طلا** با به‌روزرسانی آنلاین
- **مبدل واحد** (طول، زمان، زاویه و …)

### تقویم
- تقویم **شمسی** (پیش‌فرض)، **میلادی** و **قمری** در یک نما
- تبدیل تاریخ بین هر سه گاه‌شماری
- نمایش مناسبت‌ها با لمس هر روز

### شخصی‌سازی
- تم‌های متنوع (روشن / تیره و حال‌وهواهای فصلی و …)
- ساخت تم از **عکس دلخواه** (استخراج رنگ)
- صدا و ویبره دکمه‌ها (قابل خاموش/روشن)
- فونت فارسی **وزیرمتن**

از بخش [Releases](https://github.com/majidbusy09-blip/hesabgar_man/releases) آخرین فایل را دانلود کنید:

| فایل | کاربرد |
|------|--------|

| `.aab` | انتشار در Google Play |

## ساخت از روی سورس

پیش‌نیاز: [Flutter](https://flutter.dev) پایدار (Stable) و JDK ۱۷

```bash
git clone https://github.com/majidbusy09-blip/hesabgar_man.git
cd hesabgar_man
flutter pub get
flutter run
```

### خروجی انتشار

```bash
# نصب‌مستقیم
flutter build apk --release

# بستهٔ فروشگاهی (Play)
flutter build appbundle --release
```

خروجی‌ها:
- `build/app/outputs/flutter-apk/app-release.apk`
- `build/app/outputs/bundle/release/app-release.aab`

> برای امضای رسمی، فایل keystore و تنظیمات `key.properties` را مطابق مستندات اندروید پیکربندی کنید. در این مخزن بیلد خودکار GitHub Actions در صورت تنظیم Secrets امضا را انجام می‌دهد.

## ساختار پروژه

```
lib/
  main.dart          # نقطه شروع و تم
  core.dart          # هسته مشترک، ذخیره‌سازی، بازخورد
  features.dart      # ماشین‌حساب، مالی، تقویم، هزینه، تنظیمات
assets/
  brand/             # آیکون و برند
  fonts/             # وزیرمتن (در بیلد CI دریافت می‌شود)
  sounds/            # صدای دکمه
.github/workflows/   # بیلد خودکار APK و AAB
```
